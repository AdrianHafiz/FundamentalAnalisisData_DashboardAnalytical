# FundamentalAnalisisData_DashboardAnalytical

# Analisis E-Commerce Olist (São Paulo)
Proyek ini berisi proses Exploratory Data Analysis, Segmentasi RFM, dan Dashboard interaktif.

## Cara Menjalankan Dashboard Secara Lokal
1. Buka terminal/command prompt.
2. Arahkan ke folder `dashboard` dengan mengetik `cd dashboard`
3. Install dependencies: `pip install -r ../requirements.txt`
4. Jalankan aplikasi: `python -m streamlit run dashboard.py`
